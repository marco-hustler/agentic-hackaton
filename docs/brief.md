## Partner challenges relevant to Commerce

On the Commerce track (or “either track”), these challenges matter most. Official PDFs live in `briefs/`.

### 1. idealo — *Build Something We Didn’t Expect* (Commerce track)

| | |
|---|---|
| **Award** | Most Creative Use of the idealo MCP |
| **Deadline** | Fri 27 Nov, 19:45 CET |

**Task:** an application, agent, experience, or prototype that uses idealo commerce data (via **idealo MCP**) to solve a real problem. The data must be *essential* to the outcome.

MCP data: product catalog, category relationships, current and historical prices, availability, merchants and offers.

Examples suggested in the brief:

- Help decide whether to buy, wait, repair, rent, or replace  
- Use price/availability signals for scarcity or budget planning  
- Ideas *outside* classic shopping, if commerce data makes them possible  

**Judging criteria**

| Criterion | Question |
|---|---|
| Creativity | Unexpected use of the idealo MCP? |
| Meaningfulness | Real problem? For whom? |
| Use of the data | Product / price / availability / merchant / category drive the outcome? |
| Execution | Does the prototype make the idea and potential tangible? |

---

### 2. Affinidi / Trust Boris — *Build agents you’d confidently offer publicly* (either track)

Trust infrastructure: identity, tool gating, screening, limits.  
Strong Commerce angle: show what you can **delegate** (spend, messages, risky tools) *because* trust is there from the start.

Commerce examples in the brief: supplier comparison only for the buying team; everyone checks stock, only admins change prices; shopping assistant that holds up under traffic.

**Pre-kickoff setup:** account on [trustboris.ai](https://trustboris.ai) + Boris CLI (see brief PDF, p. 4).

---

### 3. Norma by Quality Clouds — *Ship agent code your team can defend* (either track)

Governance on agent-written code (MCP + GitHub App). Can be stacked on the same commerce build.

Requirements: same checks for every author, ≥2 PRs from different authors, at least 1 finding fixed, `DEFENCE.md` in root.  
Award: €150 Amazon gift card (team).
